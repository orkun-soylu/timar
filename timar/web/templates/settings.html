A MAC marks the machine as on-demand: it shows as asleep rather than down when off, and updates wake it, update it, and shut it back down.

OpenWrt has no default on purpose: an unattended upgrade can fill the overlay partition or land a kernel-module mismatch, and the machine that breaks is the one carrying the session you would repair it from. Leave this empty and the host is swept for logs but never updated.
