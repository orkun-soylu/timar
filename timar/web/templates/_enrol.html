Install it

Connects once as {{ enrol.server.user }}@{{ enrol.server.host }} with the password, appends the key to {{ enrol.platform.authorized_keys }}, then proves the key works on its own. The password is used for this request and nothing else — it is not stored, not logged, and not sent back to this page.

Writes {{ enrol.server.user }} ALL=(ALL) NOPASSWD:ALL to /etc/sudoers.d/timar. The file is validated with visudo before it is put in place — if validation fails nothing is changed, because a malformed sudoers file breaks sudo for everyone on the machine, including the session you would repair it from.
